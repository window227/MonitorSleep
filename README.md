# 显示器睡眠助手

**一个 Windows 托盘小工具：想省电时一键关掉显示器（或让整台电脑睡眠），不该关的时候绝不关。**

Windows 自带的「N 分钟后关闭显示」是个死板计时器 —— 看视频、开会、跑全屏程序时照关不误。
本程序会先判断「现在该不该关」，看完视频、开完会再关。

不需要管理员权限，不依赖任何第三方库。

## 快速开始

到 [Releases](https://github.com/window227/MonitorSleep/releases) 下载 zip 解压，
双击里面的 `MonitorSleep.exe` 就能用。

> 需要 **.NET 8 桌面运行时**。没装的话去微软官网搜 ".NET Desktop Runtime 8"。

**看不到托盘图标？** Windows 11 默认把新出现的图标折叠进右下角的 `^` 里，点开就能找到。
想让它常驻：右键任务栏 → 任务栏设置 → **其他系统托盘图标** → 把本程序打开。

> 任何时候**双击 `MonitorSleep.exe`** 都会直接打开设置窗口，图标被藏起来也不影响使用。

## 怎么用

| 想做什么 | 怎么做 |
|---|---|
| **关屏** | `Ctrl + Alt + O`，或托盘菜单 |
| **让电脑睡眠** | `Ctrl + Alt + S`，或托盘菜单 |
| **定时关屏 / 定时睡眠** | 托盘菜单，或「设置 → 基本 → 定时」 |
| **打开设置** | 托盘菜单 → 设置，或双击 exe |
| **唤醒屏幕** | 动一下键鼠就行，不需要任何操作 |

关屏和睡眠都会先弹一个倒计时，**按 `ESC` 可以取消**。

## 它能做什么

- **空闲自动关屏** —— 多久没动就关，时长自己定
- **智能避让** —— 全屏、摄像头/麦克风被占用、指定进程在跑的时候保持常亮
- **电脑睡眠** —— 手动或定时，和关屏一样有可取消的倒计时
- **定时关屏 / 定时睡眠** —— 5 到 120 分钟后执行
- **可选「接管系统关屏」** —— 默认关闭，见下方说明
- **开机自动启动**
- **设置界面六页** —— 基本 / 自动关屏 / 智能避让 / 行为 / 高级 / 关于

## 两个默认关闭的重要选项

**「接管系统关屏」默认关闭。** 打开它会把 Windows 自己的关屏超时改成「从不」，改由本程序判断。
好处是看视频时不会被系统关掉；代价是一旦本程序被强杀或判断出错，屏幕就再也不会自动关闭。
保留系统超时当兜底更稳妥，只有确实需要时才打开。

**「播放音频时保持常亮」默认关闭。** 音频峰值检测分不出「视频」和「音乐」，
打开后听音乐时屏幕也会一直亮着。Windows 只对视频设置显示请求，所以默认交给系统判断。
